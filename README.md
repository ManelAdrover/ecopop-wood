## Què és EcoPop Wood?

EcoPop Wood és un projecte escolar que crea figures decoratives d’estil Funko utilitzant materials reciclats (fusta i cartró) i tecnologia de tall làser.

L’objectiu és oferir una alternativa **sostenible**, **artesanal** i **personalitzable** als col·leccionables de plàstic industrials.

### Característiques principals

- Materials 100% reutilitzats (fusta i cartró)
- Disseny digital + tall làser
- Muntatge i acabat manual
- Possibilitat de personalitzar amb persones reals
- Producció local a Mallorca

## Com publicar la web a GitHub Pages

1. Crea un repositori nou a GitHub anomenat `ecopop-wood` (o el nom que vulguis).
2. Puja els fitxers d’aquesta carpeta al repositori.
3. Ves a **Settings → Pages**.
4. A **Source** selecciona la branca `main` i la carpeta `/ (root)`.
5. Desa els canvis.
6. Al cap d’uns minuts la web estarà disponible a:
   `https://TU-USUARI.github.io/ecopop-wood/`
